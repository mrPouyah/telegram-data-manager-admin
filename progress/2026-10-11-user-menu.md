# 2026-10-11 — Approved user menu

## Added

- `src/telegram_manager/user_panel.py`: persistent Persian buttons for Send Content, Search and Retrieve Content, Help, and User Menu. Send and Search explain that these workflows are not active yet.
- `src/telegram_manager/access_bot.py`: sends the user keyboard immediately after approval and on `/start` or `/menu`; routes approved users' button text; handles file-only messages without crashing and explicitly says they were not saved or published.
- `src/telegram_manager/admin_panel.py`: removes the user keyboard when access is revoked.
- `tests/test_access_bot.py`: checks the approval keyboard, menu actions, unapproved access, file-only handling, and revocation.
- `README.md`: describes current behavior and limits.

## Verified

- All 22 local tests pass using Python 3.13.
- The updated bot was started with the configured group, and its Python process was confirmed running.

## Current limits

- The buttons are navigation only. Topic registration, guided submission, publication, and approved-user retrieval are not implemented yet.
- The existing catalog still requires project permissions; it must be aligned with the agreed approval-based access model before enabling user search or publishing.
